# Curriculum mapping

| Unit | Implementation |
|---|---|
| I · Foundations | Pandas, NumPy, scikit-learn, interactive Plotly charts, supervised ranking and unsupervised exploration |
| II · Preprocessing | CSV audit, exact duplicate removal in generated profiles, explicit feature selection, one-hot encoding, imputation and numeric standardization. L2 normalization supports clustering, and PCA extracts display coordinates. |
| III · Supervised learning | Logistic Regression, Decision Tree, Random Forest and k-Nearest Neighbors, with binary relevance as the prediction target |
| IV · Unsupervised learning | K-Means with a silhouette comparison over 2–5 clusters and a two-component PCA plot |
| V · Evaluation | Profile-grouped holdout and five-fold CV, GridSearchCV, CV F1 selection, train-vs-validation diagnostics, accuracy, precision, recall, F1 and confusion matrices |
| VI · Application | Welfare discovery, checks tied to official sources, uncertainty reporting, no persistence of applicant profiles, and exclusion of gender and domicile from ML inputs |
